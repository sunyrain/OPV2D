OPV-DB v2.0.0 public data

Dataset DOI: https://doi.org/10.5281/zenodo.23951239

The seven CSV tables, field dictionary, subset rules, citation and attribution files are copied from the published archive. The complete ZIP is the unchanged Zenodo archive. Binary CSV preserves the 37-column schema; binary_supplement.csv supplies the linked additional fields. Binary JSON and browser details join these two tables by id. Ternary and indoor JSON retain their respective table values. The filtered CSV export contains display fields, not the complete release schema.

The primary binary table has 32,778 records from 7,360 source DOIs. Strict performance and strict molecular subsets contain 27,863 and 19,299 records. Ternary: 2,588 records from 461 DOIs. Indoor: 1,678 records from 166 DOIs. Material reference: 4,988 entries. Ternary and indoor literature coverage is partial.

The principal PCE retains the reported statistic of each observation. Explicit mean and best values are retained separately where available; per-metric descriptions and source notes provide context. Indoor Jsc uses microamperes/cm2 and irradiance uses microwatts/cm2. Lux is separate.

The browser uses the deposited subset membership. It does not infer missing illumination or area, assign specialist SMILES, or exclude additional published records. Sources and observations can overlap across topics.

The archive-v1.1.0.html page, Active_Database.csv and opv_data.json are retained as explicitly historical v1.1.0 resources.
